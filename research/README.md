# Research

`jt5295-rom-00100000-64k.bin` is a dump of the JT5295 BootROM (64 KiB mapped at `0x00100000`), for use with
the Ghidra language module [`ghidra-appotech-jt5295`](https://github.com/matu6968/ghidra-appotech-jt5295). The measurement files and flash/RAM captures cited by
`../docs/*.md` were removed before publication; file names in those reports without a link refer to them.
